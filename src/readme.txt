EMAS-3 files
============

This is a collection of EMAS-3 files; some from about 1986, and others
from about 1988. They form two separate snapshots, and I have tried to
sort them out as such where possible; however, don't reply on me getting
it all right!

As I recall, the earlier set are from when I was getting EMAS-3 to work
on the XA architecture (taking IPL tapes from Canterbury to Greenford two
or three days a week), and the later set are files I got out of
interest. I have put the two sets (where appropriate) in subdirectories
named 'old' and 'new'.

In general, these files are not as well organised as my EMAS-2 collection;
remember I was working from 400 miles away, and the only file transfer was
over a rather unreliable JANET connection! I only collected new files
when I had to...

The directories are as follows:

chopsupe        CHOPped down SUPErvisor - system loader.
supervisor      Main supervisor.

director        Director (including DIRECT process).
volumes         Volumes process (VOLUMS).
spooler         Spooler process (SPOOLR).
mailer          Mail process (MAILER).
ftrans          File transfer process (FTRANS).

subsystem       The Edinburgh Subsystem and related commands and support.
eutils          Utilities, really for building system.
xautils         Utilities, mainly by Bob Eager, for XA implementation.

managr          System manager utilities.

docs            Miscellaneous documents. Some of these make very interesting
                reading!

Bob Eager
August 2002
